# 小小预习家 · 二年级语文

2025 秋统编版二年级上册预习小站。手机上打开就能用：先选单元，再选一课，认一认、读一读、练一练。没有账号，进度只存在这台手机的浏览器里。

在线地址：<https://shanelau068-a11y.github.io/xiaoxiao-yuxi/>

## 怎么用

- **GitHub Pages**：推送到 `master` 后，按仓库 Pages 设置打开上面的地址。
- **本地打开**：下载后用浏览器打开 `index.html`。朗读功能在手机 Chrome 上更稳。若要离线预习，用手机浏览器“添加到主屏幕”（PWA）。
- 每次大约 10–15 分钟。点「今日学习」从下一课开始，点「继续上次」回到刚看的那一课。
- 右上角 ↺ 可以轻轻清掉本地进度。

## 学什么

目录按 2025 秋统编版公开课程地图整理：

- 8 个单元，23 篇课文 + 4 课识字 + 8 个语文园地 + 快乐读书吧
- 《古诗二首》拆成独立预习卡：登鹳雀楼、望庐山瀑布、敕勒歌、江雪
- 每一课都有：孩子能听懂的预习目标、课文或古诗正文、生字词卡片、3 道小练习
- 语文园地 / 快乐读书吧是轻活动卡，不是空任务

课文正文作为朗读预习文本收录在仓库里，方便孩子在手机上读。请以纸质课本为准。本站不提供教材插图、扫描件或 PDF。

## 和旧版的差别

旧部编版二年级上册第三单元是《曹冲称象》《玲玲的画》等，第七单元古诗是《夜宿山寺》《敕勒歌》，第八单元有《狐假虎威》。2025 秋公开目录改为《彩虹》《去外婆家》《数星星的孩子》，古诗为《敕勒歌》《江雪》，第八单元课文为《称赞》《纸船和风筝》《快乐的小河》。《夜宿山寺》收在第七单元园地的日积月累。

个别 2025 新课文（《彩虹》《去外婆家》《快乐的小河》）正文来自公开课件与教学材料，若与手中课本有出入，以课本为准。

## 技术

静态 HTML / CSS / JS，无构建、无后端。PWA：`manifest.webmanifest` + `sw.js`。交互思路参考了开源预习站的「今日学习 / 课程地图 / 认读练」节奏，界面和内容按家庭预习重新写过。
