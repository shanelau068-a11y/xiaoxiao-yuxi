# 小小预习家 · 二年级语文

手机优先的静态 PWA 预习小站，当前内容参考家长提供的课本照片，制作了人教版二年级上册第四单元第 10 课《古诗二首》中的《登鹳雀楼》预习内容。

## 功能

- 生字词卡片：拼音、释义、上一个/下一个、掌握记录
- 古诗朗读：诗文展示与朗读完成标记
- 诗意小讲堂：用更容易理解的话解释诗句
- 小小挑战：3 道选择题，进度保存在手机浏览器本地
- GitHub Pages 可直接部署，无需后端和账号

## 本地运行

直接双击 `index.html` 即可预览；部署到 GitHub Pages 后可在手机打开。

## 参考

交互思路参考了开源项目 [tnm/hsk](https://github.com/tnm/hsk) 的响应式闪卡、学习进度与本地存储模式，并按家庭预习场景重新设计界面和内容。
