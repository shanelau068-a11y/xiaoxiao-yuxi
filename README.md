# 小小预习家 · 二年级语文

手机优先的静态 PWA 预习小站，已加入 2025 秋统编版二年级上册整册课程地图：8 个单元、23 个课次入口；并保留家长提供照片中的《登鹳雀楼》作为详细示范课。

## 功能

- 整册课程地图：单元目标、逐课入口、预习任务卡
- 生字词卡片：拼音、释义、上一个/下一个、掌握记录
- 古诗朗读、诗意讲解、小测验
- 学习进度保存在手机浏览器本地
- GitHub Pages 可直接部署，无需后端和账号

## 说明

目录依据人民教育出版社公开的二年级上册目录，以及 2025 秋修订版公开课程目录整理；课文正文、插图和完整课后练习没有复制到公开仓库，请以孩子手上的纸质课本为准。这样既能覆盖整本书的学习路径，也避免把受版权保护的教材全文公开发布。

## 参考项目

交互思路参考了开源项目 [tnm/hsk](https://github.com/tnm/hsk) 与 GitHub 上的 [ajpeng/chinese-flashcards](https://github.com/ajpeng/chinese-flashcards) 的卡片/进度模式，并按家庭预习场景重新设计界面和内容。
